# README 图片说明

这里保存 README 正式使用的图片。素材来自本项目的界面、图标与棋盘插画。

## 图片来源

界面素材于 2026 年 11 月 2 日从本项目 Electron 生产构建中截取，对应应用代码提交 `d671555`。截图时实际加载了随项目准备的 Rapfi 250615 引擎与 NNUE 权重，没有替换接口、模拟模型落子或修改概率。

| 文件                 | 内容与来源                                                                                                                                  |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `cover.webp`         | 原创封面，复用 `public/favicon.svg` 与 `src/components/BoardArt.tsx` 的项目图形，重新设计文案、背景和排版。封面棋盘是插画，不是对局截图。   |
| `single-player.webp` | 真实人机对局的内容区域截图，玩家执黑、普通难度，外加标题、说明和装饰窗口边框。                                                              |
| `analysis.webp`      | 同一盘双人棋局的棋盘、当前第 12 手分析及回看第 7 手的分析面板，裁剪后并排展示。                                                             |
| `winning-line.gif`   | 真实客户端的第五子落下、获胜划线和悔棋画面，外加阶段标签。原动画逐帧采样，划线时长仍为 0.7 秒，起止和悔棋画面延长停留方便阅读。GIF 无音轨。 |
| `lobby.webp`         | 对弈大厅的完整内容截图，外加标题与装饰窗口边框。                                                                                            |
| `setup.webp`         | 三档棋力与执子设置弹窗的实际截图，外加背景与说明。                                                                                          |
| `badges.svg`         | 本地静态标签，说明当前平台、推理方式与项目许可证，不表示构建状态或第三方引擎许可证。                                                        |

静态图片使用 WebP，动图使用 GIF；标签使用 SVG。所有图片通过仓库相对路径引用，无需外部图床。图中的窗口边框只用于展示排版，不代表客户端新增界面。

## 后续更新

1. 按[开发与验证](../../development.md)准备依赖和引擎，使用当前源码构建 Electron 前端与主进程。
2. 打开独立的客户端会话，等待中文字体和真实模型就绪，内容区域设置为约 1440 × 1120。
3. 通过正常交互截取大厅、执子设置、人机对弈和分析面板。每次落子后等分析完成再截图，避免把加载状态当成结果。
4. 分析示例落子顺序为 `H8、I8、H9、I9、J8、J9、G8、F8、G9、I7、H10、H7`，再通过曲线方向键查看第 7 手。
5. 获胜示例落子顺序为 `D8、A1、E8、C1、F8、E1、G8、G1、H8`，随后点击悔棋。逐帧捕获已有 CSS 动画，保留实际绘制时长。
6. 为静态截图添加统一背景和标题，压缩图片并更新此处的来源日期与提交号；检查 README 中的文字、截图和当前功能一致。

原始截图、采样脚本、临时渲染页面和客户端运行文件保留在被 Git 忽略的 `.local/`，本目录仅保存正式展示素材及说明。
